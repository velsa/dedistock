# Dedistock

Live site: https://dedistock.com

Dedicated servers and VPS you can order right now (EU).

The page lists offers from OVH Eco, Hetzner server auction, Hetzner Cloud, OVH VPS and Netcup.
The data in `radar.json` is refreshed every 10 minutes.

- OVH Eco: only servers that OVH marks "ready in about 1 hour".
- Prices are per month, excluding VAT. Check the host's page before you order.
- Dedistock does not sell servers. Links go to the host.
